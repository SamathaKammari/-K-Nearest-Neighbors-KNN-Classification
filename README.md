Task Implementation: KNN with Iris Dataset
Dataset Description
Features:
Sepal length (cm)
Sepal width (cm)
Petal length (cm)
Petal width (cm)
Target: Iris species (Iris-setosa, Iris-versicolor, Iris-virginica)
Size: 150 samples, 3 classes (50 samples per class)
Preprocessing: No missing values; normalization required for KNN.
